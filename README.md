# Plataforma de Gestión Académica para Institutos de Formación Continua

## Descripción del Proyecto
Sistema de gestión integral para institutos de formación que permite administrar usuarios, cursos, cohortes, inscripciones, pagos de alumnos y liquidación a docentes.
